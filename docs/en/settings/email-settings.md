# 1. Sender information

In this section, you can set the sender information and the footer for all outgoing emails. 
This ensures consistent communication with your customers and partners, 
giving you the ability to add a professional signature and company information to each email.


# 2. Email server
You can also configure whether you want to use a different email server for sending emails. 
This is useful if you want to use a specific mail server from your own domain
or if you wish to configure advanced settings for better deliverability and control over your email traffic.
