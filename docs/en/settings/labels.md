# 1. Create labels

In this section, you can easily create new labels to add extra categories or tags to your data. 
These labels can be used to organize information, such as projects, customers, or tasks, helping you quickly find relevant data. 
By adding a name and description to each label, you create a structured system that aligns with your business needs.

# 2. Edit labels

Here you can edit existing labels to ensure they remain up-to-date and relevant. 
This might be necessary when a project name changes or when you want to clarify the meaning of a label. 
By editing labels, you maintain a consistent and efficient way of managing your data.
