# 1. Create Task
Tasks are a convenient way to keep track of what needs to be done. 
You can create tasks for yourself or for other team members. 
Additionally, tasks can be linked to specific contacts, making it easy to manage the progress of projects and interactions.

# 2. Assign Tasks
Assign tasks to other team members by entering their name and linking the task to them. 
This helps clearly distribute responsibilities and ensures everyone knows which actions they need to take.

# 3. Deadlines
Set deadlines for tasks to ensure they are completed within the specified time frame.
This helps prioritize tasks and ensures that important actions are not overlooked.

# 4. Mark Tasks as Completed
Once a task is completed, you can mark it as done. 
This helps you track your progress and gives you a clear overview of what still needs to be done and what has already been finished.

# 5. Filter
Use the filter option to sort tasks based on their status, such as open, closed, or deleted. 
This makes it easy to get an overview of which tasks still need attention and which have already been completed.
