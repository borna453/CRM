# 1. User overview

Here you can find an overview of all users within the portal, along with their corresponding authorizations.
This gives you insight into the access levels and rights each user has within the system.

# 2. Add user

Adding a new user is simple via the 'Add User' button on the right-hand side of the screen.
This allows you to quickly give new users access to the portal and assign them the appropriate permissions.

# 3. Edit User

If necessary, you can also edit existing users here, for example, to adjust their authorizations or modify other details.
