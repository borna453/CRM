# 1. Personaliseer

Je kunt je account visueel aanpassen door verschillende beelden toe te voegen, 
zoals een logo voor zowel de dark mode als de light mode, zodat je branding er consistent uitziet in beide weergaven. 
Daarnaast kun je ook de favicon van de site aanpassen.

# Favicons
Een favicon is een klein pictogram dat wordt weergegeven in de browser tab naast de paginatitel. 
Het helpt gebruikers om je website snel te herkennen wanneer er meerdere tabbladen zijn geopend.
Het is een klein maar belangrijk onderdeel van je visuele identiteit en draagt bij aan de professionele uitstraling van je website.
